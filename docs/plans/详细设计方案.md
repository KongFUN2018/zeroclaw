# 技能跨生态转换器

> **Write once, run on any Agent ecosystem**
> 一次编写，在任何 Agent 生态中运行

---

## 一、产品定位

```
问题：
  AI Agent 生态碎片化
  OpenClaw / NanoBot / PicoClaw / ZeroClaw / NullClaw
  每个生态都有"技能"概念，但格式互不兼容
  开发者被迫为每个生态重写技能定义

解决：
  SkillPort = Agent 生态的 Babel + npm
  
  Babel 层：技能格式互转（OpenClaw ↔ NanoBot ↔ PicoClaw ...）
  npm  层：技能市场，发布一次，所有生态可用

核心价值：
  开发者 → 技能写一次，覆盖所有生态，用户量 ×5
  使用者 → 不被生态锁定，任何好技能都能用
  生态方 → 技能供给量瞬间扩大，冷启动破局
```

---

## 二、核心概念

### 2.1 技能（Skill）— 转换的原子单元

```
技能 = Agent 能执行的一个原子能力

┌─────────────────────────────────────────┐
│  技能的本质结构                          │
│                                          │
│  ┌─────────┐                             │
│  │ 身份    │  名称、版本、作者、描述      │
│  ├─────────┤                             │
│  │ 接口    │  输入参数、输出结果          │
│  ├─────────┤                             │
│  │ 逻辑    │  执行步骤 / 提示词 / 代码   │
│  ├─────────┤                             │
│  │ 权限    │  需要什么系统能力            │
│  ├─────────┤                             │
│  │ 依赖    │  依赖哪些其他技能/库         │
│  ├─────────┤                             │
│  │ 测试    │  验证用例                    │
│  └─────────┘                             │
└─────────────────────────────────────────┘

每个生态都有技能，只是定义方式不同：

  OpenClaw  → skill.yaml / skill.toml
  NanoBot   → tool.json / function schema
  PicoClaw  → action.pico
  ZeroClaw  → capability.zero
  NullClaw  → fn.null
```

### 2.2 USF（Universal Skill Format）— 中间表示

```
转换路径：

  源技能定义 → USF（通用技能格式）→ 目标技能定义

  不做 N×N 两两转换
  每个生态只需实现 2 个方法：
    parse:    本生态格式 → USF
    generate: USF → 本生态格式

  5 个生态 = 10 个方法（而非 20 个）
  新增一个生态 = 只加 2 个方法
```

### 2.3 适配器（Adapter）— 生态桥接

```
每个生态一个适配器，职责：

  ┌──────────────────────────────────────────┐
  │  Adapter                                  │
  │                                           │
  │  detect()   → 识别是否为此生态格式         │
  │  parse()    → 原生格式 → USF              │
  │  generate() → USF → 原生格式              │
  │  loss_report() → 转换损失评估             │
  └──────────────────────────────────────────┘
```

### 2.4 保真度（Fidelity）— 转换质量度量

```
不是所有转换都无损
保真度 = 转换后保留了多少原始语义

  1.00  完美转换，零损失
  0.95  极小损失（如 model_hint 丢失）
  0.85  可接受损失（如 prompt 结构合并）
  0.70  显著损失（如 code 逻辑降级为 prompt）
  <0.60 不建议转换

用户设定最低保真度阈值，低于则拒绝转换
```

### USF 类型系统

```
支持的字段类型：

  基础类型：
    string    UTF-8 字符串，可选 max_length / min_length / pattern
    int       整数，可选 range
    float     浮点数，可选 range
    bool      布尔值
    enum      枚举，必须声明 values

  复合类型：
    array     数组，通过 item_schema 定义元素结构
    object    对象，通过 schema 定义字段
    map       键值对，通过 key_type / value_type 定义

  特殊类型：
    file      文件引用（路径或 base64）
    any       任意类型（降低保真度）
```

### USF Logic 四种模式

```
┌──────────┬────────────────────────────────────────────┐
│ prompt   │ 纯提示词驱动                                │
│          │ system + user 模板，变量插值                 │
│          │ 最通用，所有生态都支持                       │
├──────────┼────────────────────────────────────────────┤
│ code     │ 可执行代码                                  │
│          │ 指定 runtime / entrypoint / function        │
│          │ 需要目标生态支持对应运行时                   │
├──────────┼────────────────────────────────────────────┤
│ hybrid   │ 代码 + 提示词混合                           │
│          │ pre_process (code) → main (prompt) →        │
│          │ post_process (code)                         │
│          │ 适合需要数据预处理/后处理的场景              │
├──────────┼────────────────────────────────────────────┤
│ chain    │ 技能编排                                    │
│          │ 多个子技能串联执行                           │
│          │ 通过 map_inputs 传递数据                    │
│          │ 适合复杂多步任务                             │
└──────────┴────────────────────────────────────────────┘

各生态对 logic 类型的支持度：

           prompt  code  hybrid  chain
OpenClaw    ✅      ✅     ✅      ✅
NanoBot     ✅      ✅     🟡      ✅
PicoClaw    ✅      ❌     ❌      🟡
ZeroClaw    ✅      ✅     ✅      ✅
NullClaw    ✅      ✅     ❌      ❌

✅ 原生支持  🟡 有损支持  ❌ 不支持
```

### 4.2 转换流程

```
输入                                                    输出
  │                                                       ▲
  ▼                                                       │
┌──────┐    ┌──────┐    ┌──────┐    ┌──────┐    ┌──────┐
│ 检测  │───▶│ 解析  │───▶│ 扫描  │───▶│ 评估  │───▶│ 生成  │
│      │    │      │    │      │    │      │    │      │
│识别源 │    │原生格式│    │安全检查│    │损失评估│    │目标格式│
│生态   │    │→ USF  │    │      │    │保真度  │    │USF →  │
└──────┘    └──────┘    └──────┘    └──────┘    └──────┘
                           │           │
                           ▼           ▼
                      安全报告     损失报告
                      (给用户)    (给用户)

任何一步失败都中止：
  检测失败 → "无法识别技能格式"
  解析失败 → "技能定义不合法"
  扫描失败 → "存在安全风险，拒绝转换"
  评估失败 → "保真度低于阈值，不建议转换"
  生成失败 → "目标生态不支持此技能类型"
```

### 5.2 核心类型定义

```rust
// crates/usf-core/src/types.rs

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};
use std::collections::HashMap;

/// USF 文档根结构
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct UsfDocument {
    pub usf: UsfMeta,
    pub identity: Identity,
    pub interface: Interface,
    pub logic: Logic,
    pub permissions: Permissions,
    #[serde(default)]
    pub dependencies: Vec<Dependency>,
    #[serde(default)]
    pub tests: Vec<TestCase>,
    #[serde(default)]
    pub compatibility: HashMap<String, String>,
    pub signature: Option<Signature>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct UsfMeta {
    pub version: String,
}

/// 技能身份
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Identity {
    pub name: String,
    pub version: String,
    pub description: String,
    pub author: String,
    pub author_key: Option<String>,
    pub license: Option<String>,
    #[serde(default)]
    pub tags: Vec<String>,
    pub created: Option<DateTime<Utc>>,
    pub source_ecosystem: Option<String>,
    pub source_hash: Option<String>,
}

/// 技能接口
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Interface {
    pub inputs: Vec<ParamDef>,
    pub outputs: Vec<ParamDef>,
}

/// 参数定义
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ParamDef {
    pub name: String,
    #[serde(rename = "type")]
    pub param_type: ParamType,
    #[serde(default = "default_true")]
    pub required: bool,
    pub default: Option<serde_json::Value>,
    pub description: Option<String>,
    // 类型特定约束
    pub max_length: Option<usize>,
    pub min_length: Option<usize>,
    pub pattern: Option<String>,
    pub range: Option<(f64, f64)>,
    pub values: Option<Vec<String>>,       // enum 用
    pub item_schema: Option<HashMap<String, String>>, // array 用
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum ParamType {
    String,
    Int,
    Float,
    Bool,
    Enum,
    Array,
    Object,
    Map,
    File,
    Any,
}

/// 执行逻辑
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "lowercase")]
pub enum Logic {
    Prompt(PromptLogic),
    Code(CodeLogic),
    Hybrid(HybridLogic),
    Chain(ChainLogic),
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PromptLogic {
    pub system: String,
    pub user: String,
    pub model_hint: Option<String>,
    pub temperature: Option<f64>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CodeLogic {
    pub runtime: String,        // "python" | "javascript" | "rust" | ...
    pub entrypoint: String,
    pub function: String,
    pub source: Option<String>, // 内联代码（小型技能）
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct HybridLogic {
    pub pre_process: Option<CodeLogic>,
    pub main: Box<Logic>,
    pub post_process: Option<CodeLogic>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ChainLogic {
    pub steps: Vec<ChainStep>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ChainStep {
    pub skill: String,
    pub version: Option<String>,
    pub map_inputs: HashMap<String, String>,
}

/// 权限声明
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Permissions {
    #[serde(default = "default_none")]
    pub network: AccessLevel,
    #[serde(default = "default_none")]
    pub filesystem: AccessLevel,
    #[serde(default)]
    pub subprocess: bool,
    #[serde(default)]
    pub env_access: bool,
    pub max_memory_mb: Option<u32>,
    pub max_execution_seconds: Option<u32>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum AccessLevel {
    None,
    Readonly,

pub struct ConvertEngine {
    registry: AdapterRegistry,
    scanner: SecurityScanner,

impl ConvertEngine {
    pub fn new() -> Self {
        let mut registry = AdapterRegistry::new();
        registry.register(Box::new(OpenClawAdapter::new()));
        registry.register(Box::new(NanoBotAdapter::new()));
        registry.register(Box::new(PicoClawAdapter::new()));
        registry.register(Box::new(ZeroClawAdapter::new()));
        registry.register(Box::new(NullClawAdapter::new()));

        Self {
            registry,
            scanner: SecurityScanner::new(),
        }
    }

    /// 核心转换方法
    pub fn convert(
        &self,
        raw: &[u8],
        source: &str,
        target: &str,
        options: &ConvertOptions,
    ) -> Result<ConvertResult, ConvertError> {
        let source_adapter = self.registry.get(source)?;
        let target_adapter = self.registry.get(target)?;

        // 1. 解析为 USF
        let usf = source_adapter.parse(raw)?;

        // 2. 安全扫描
        let security_report = if !options.skip_security {
            let report = self.scanner.scan(&usf, options.security_level)?;
            if report.has_critical() {
                return Err(ConvertError::SecurityBlocked(report));
            }
            Some(report)
        } else {
            None
        };

        // 3. 损失评估
        let loss_report = target_adapter.loss_report(&usf);
        if loss_report.fidelity < options.min_fidelity {
            return Err(ConvertError::FidelityTooLow {
                actual: loss_report.fidelity,
                required: options.min_fidelity,
                report: loss_report,
            });
        }

        // 4. 生成目标格式
        let output = target_adapter.generate(&usf)?;

        Ok(ConvertResult {
            data: output,
            usf,
            security_report,
            loss_report,
            source_ecosystem: source.to_string(),
            target_ecosystem: target.to_string(),
        })
    }

    /// 自动检测源格式并转换
    pub fn convert_auto(
        &self,
        raw: &[u8],
        target: &str,
        options: &ConvertOptions,
    ) -> Result<ConvertResult, ConvertError> {
        let source = self.registry.detect(raw)?;
        self.convert(raw, source, target, options)
    }

    /// 转换到所有支持的生态
    pub fn convert_all(
        &self,
        raw: &[u8],
        source: &str,
        options: &ConvertOptions,
    ) -> Result<Vec<ConvertResult>, ConvertError> {
        let mut results = Vec::new();
        for ecosystem in self.registry.ecosystems() {
            if ecosystem == source {
                continue;
            }
            match self.convert(raw, source, ecosystem, options) {
                Ok(result) => results.push(result),
                Err(ConvertError::FidelityTooLow { .. }) => {
                    // 保真度不够，跳过但不报错
                    continue;
                }
                Err(e) => return Err(e),
            }
        }
        Ok(results)
    }
}

}

impl Default for ConvertOptions {

            preserved,
            degraded,
            lost,
            fidelity: fidelity.max(0.0),
        }
    }

pub struct PicoClawAdapter;

impl SkillAdapter for PicoClawAdapter {

        let mut lost = Vec::new();

        // Logic 损失评估
        match &usf.logic {
            Logic::Prompt(p) => {
                // PicoClaw 不支持 system/user 分离
                degraded.push(LossItem {
                    field: "logic.prompt".into(),
                    reason: "PicoClaw 不支持 system/user 分离，合并为单一 instruction".into(),
                    suggestion: "检查合并后的 prompt 是否语义完整".into(),
                });
                if p.model_hint.is_some() {
                    lost.push(LossItem {
                        field: "logic.prompt.model_hint".into(),
                        reason: "PicoClaw 无模型建议机制".into(),
                        suggestion: "在 PicoClaw 运行时手动配置模型".into(),
                    });
                }
                if p.temperature.is_some() {
                    lost.push(LossItem {
                        field: "logic.prompt.temperature".into(),
                        reason: "PicoClaw 不支持温度参数".into(),
                        suggestion: "使用 PicoClaw 默认温度".into(),
                    });
                }
            }
            Logic::Code(_) => {
                lost.push(LossItem {
                    field: "logic.code".into(),
                    reason: "PicoClaw 不支持代码执行".into(),
                    suggestion: "将代码逻辑改写为 prompt 描述，或选择其他生态".into(),
                });
            }
            Logic::Hybrid(_) => {
                lost.push(LossItem {
                    field: "logic.hybrid".into(),
                    reason: "PicoClaw 不支持混合模式".into(),
                    suggestion: "仅保留 prompt 部分".into(),
                });
            }
            Logic::Chain(c) => {
                degraded.push(LossItem {
                    field: "logic.chain".into(),
                    reason: "PicoClaw 仅支持线性 chain，复杂编排会被展平".into(),
                    suggestion: "检查展平后的执行顺序是否正确".into(),
                });
            }
        }

        // 测试损失
        if !usf.tests.is_empty() {
            degraded.push(LossItem {
                field: "tests".into(),
                reason: "PicoClaw 测试格式为 inline assertion，结构变化".into(),
                suggestion: "语义保留，但需要验证转换后的测试".into(),
            });
        }

        let fidelity = 1.0
            - (degraded.len() as f64 * 0.03)
            - (lost.len() as f64 * 0.08);

        LossReport {
            preserved,
            degraded,
            lost,
            fidelity: fidelity.max(0.0),
        }
    }

    fn generate(&self, usf: &UsfDocument) -> Result<Vec<u8>, AdapterError> {
        // USF → PicoClaw 极简格式
        let instruction = match &usf.logic {
            Logic::Prompt(p) => {
                // 合并 system + user
                format!("{}\n\n{}", p.system, p.user)
            }
            Logic::Code(_) => {
                return Err(AdapterError::UnsupportedLogicType(LogicType::Code));
            }
            Logic::Hybrid(h) => {
                // 只取 main 的 prompt 部分
                match h.main.as_ref() {
                    Logic::Prompt(p) => format!("{}\n\n{}", p.system, p.user),
                    _ => return Err(AdapterError::UnsupportedLogicType(LogicType::Hybrid)),

            }
            Logic::Chain(c) => {

                let steps: Vec<String> = c.steps.iter().enumerate().map(|(i, s)| {
                    format!("Step {}: Use skill '{}' with inputs: {:?}", i+1, s.skill, s.map_inputs)
                }).collect();
                steps.join("\n")
            }
        };

        let pico = PicoAction {
            name: usf.identity.name.clone(),
            version: usf.identity.version.clone(),
            description: usf.identity.description.clone(),
            instruction,
            params: usf.interface.inputs.iter().map(|i| PicoParam {
                name: i.name.clone(),
                kind: pico_type(&i.param_type),
                required: i.required,
            }).collect(),
            returns: usf.interface.outputs.iter().map(|o| PicoReturn {
                name: o.name.clone(),
                kind: pico_type(&o.param_type),
            }).collect(),
        };

        let output = pico.serialize();
        Ok(output.into_bytes())
    }

}

### 6.1 安全模型

```
技能的安全风险分类：

┌──────────────────┬───────────┬────────────────────────────────┐
│ 风险类型          │ 严重度     │ 说明                           │
├──────────────────┼───────────┼────────────────────────────────┤

│ 代码执行风险      │ High      │ 包含可执行代码，需要沙箱        │
│ 依赖链风险        │ Medium    │ 引用的子技能可能有问题          │
│ 接口边界缺失      │ Medium    │ 输入无长度限制，可能 DoS        │
│ 模板变量异常      │ Medium    │ 非法模板变量，可能是注入        │
│ 签名缺失/无效     │ Low       │ 无法验证技能来源               │
│ 测试覆盖不足      │ Info      │ 测试用例太少                   │
└──────────────────┴───────────┴────────────────────────────────┘

安全等级：
  Relaxed   → 只检查 Critical
  Standard  → 检查 Critical + High + Medium（默认）
  Strict    → 检查所有级别
  Paranoid  → 所有级别 + 最严格阈值

pub struct SecurityScanner {

impl SecurityScanner {
    pub fn new() -> Self {
        Self {
            rules: vec![
                Box::new(PromptSafetyRule),
                Box::new(CodeExecutionRiskRule),
                Box::new(PermissionConsistencyRule),
                Box::new(DependencyChainRule),
                Box::new(InterfaceBoundaryRule),
                Box::new(TemplateVariableRule),
                Box::new(SignatureValidityRule),
                Box::new(TestCoverageRule),
            ],
        }
    }

    pub fn scan(
        &self,
        usf: &UsfDocument,
        level: SecurityLevel,
    ) -> Result<SecurityReport, ScanError> {
        let mut findings = Vec::new();

        for rule in &self.rules {
            let rule_findings = rule.check(usf)?;
            findings.extend(rule_findings);
        }

        // 按安全等级过滤
        let filtered: Vec<Finding> = findings
            .into_iter()
            .filter(|f| f.severity.meets_level(level))
            .collect();

        let score = self.calculate_score(&filtered);

        Ok(SecurityReport {
            score,
            level,
            findings: filtered,
            scanned_at: Utc::now(),
        })
    }

    fn calculate_score(&self, findings: &[Finding]) -> u32 {
        let mut score: i32 = 100;
        for f in findings {
            match f.severity {
                Severity::Critical => score -= 30,
                Severity::High     => score -= 15,
                Severity::Medium   => score -= 5,
                Severity::Low      => score -= 2,
                Severity::Info     => score -= 0,
            }
        }
        score.max(0) as u32
    }
}

// crates/usf-security/src/rules/prompt_safety.rs

/// Prompt 注入检测
pub struct PromptSafetyRule;

impl SecurityRule for PromptSafetyRule {
    fn name(&self) -> &str { "prompt-safety" }

    fn check(&self, usf: &UsfDocument) -> Result<Vec<Finding>, ScanError> {
        let mut findings = Vec::new();

        if let Logic::Prompt(prompt) = &usf.logic {
            self.check_text(&prompt.system, "logic.prompt.system", &mut findings);
            self.check_text(&prompt.user, "logic.prompt.user", &mut findings);
        }

        if let Logic::Chain(chain) = &usf.logic {
            for (i, step) in chain.steps.iter().enumerate() {
                for (key, value) in &step.map_inputs {
                    self.check_text(
                        value,
                        &format!("logic.chain.steps[{}].map_inputs.{}", i, key),
                        &mut findings,
                    );
                }
            }
        }

        if let Logic::Hybrid(hybrid) = &usf.logic {
            if let Logic::Prompt(p) = hybrid.main.as_ref() {
                self.check_text(&p.system, "logic.hybrid.main.system", &mut findings);
                self.check_text(&p.user, "logic.hybrid.main.user", &mut findings);
            }
        }

        Ok(findings)
    }
}

impl PromptSafetyRule {
    fn check_text(&self, text: &str, location: &str, findings: &mut Vec<Finding>) {
        let lower = text.to_lowercase();

        // 已知注入模式
        let injection_patterns = [
            ("ignore previous",    "试图覆盖之前的指令"),

    fn name(&self) -> &str { "code-execution-risk" }

        let mut findings = Vec::new();

                findings.push(Finding {

                    message: format!(
                        "技能包含可执行代码 (runtime: {})",
                        code.runtime
                    ),
                    location: "logic.code".into(),
                    suggestion: "确保目标生态有沙箱执行环境".into(),
                });

                // 检查内联代码中的危险模式
                if let Some(source) = &code.source {
                    self.check_code_patterns(source, &code.runtime, &mut findings);
                }
            }
            Logic::Hybrid(hybrid) => {
                if hybrid.pre_process.is_some() || hybrid.post_process.is_some() {
                    findings.push(Finding {
                        severity: Severity::Medium,
                        rule: "code-execution-risk".into(),
                        message: "混合模式包含代码预/后处理".into(),
                        location: "logic.hybrid".into(),
                        suggestion: "审查预处理和后处理代码的安全性".into(),
                    });
                }
            }
            _ => {}
        }

        Ok(findings)
    }
}

impl SecurityRule for InterfaceBoundaryRule {
    fn name(&self) -> &str { "interface-boundary" }

    fn check(&self, usf: &UsfDocument) -> Result<Vec<Finding>, ScanError> {
        let mut findings = Vec::new();

        for input in &usf.interface.inputs {
            // string 类型无长度限制
            if input.param_type == ParamType::String && input.max_length.is_none() {
                findings.push(Finding {
                    severity: Severity::Medium,
                    rule: "interface-boundary".into(),
                    message: format!("输入参数 '{}' (string) 无 max_length 限制", input.name),
                    location: format!("interface.inputs.{}", input.name),
                    suggestion: "设置 max_length 防止超大输入导致 DoS".into(),
                });
            }

            // array 类型无元素 schema
            if input.param_type == ParamType::Array && input.item_schema.is_none() {
                findings.push(Finding {
                    severity: Severity::Low,
                    rule: "interface-boundary".into(),
                    message: format!("输入参数 '{}' (array) 无 item_schema", input.name),
                    location: format!("interface.inputs.{}", input.name),
                    suggestion: "定义 item_schema 确保数组元素类型安全".into(),
                });
            }

            // any 类型
            if input.param_type == ParamType::Any {
                findings.push(Finding {
                    severity: Severity::Medium,
                    rule: "interface-boundary".into(),
                    message: format!("输入参数 '{}' 使用 any 类型", input.name),
                    location: format!("interface.inputs.{}", input.name),
                    suggestion: "尽量使用具体类型以提高安全性和保真度".into(),
                });
            }
        }

        // 无输出定义
        if usf.interface.outputs.is_empty() {
            findings.push(Finding {
                severity: Severity::Low,
                rule: "interface-boundary".into(),
                message: "技能未定义输出参数".into(),
                location: "interface.outputs".into(),
                suggestion: "定义输出 schema 便于下游消费和验证".into(),
            });

pub struct DependencyChainRule;

impl SecurityRule for DependencyChainRule {
    fn name(&self) -> &str { "dependency-chain" }

    fn check(&self, usf: &UsfDocument) -> Result<Vec<Finding>, ScanError> {
        let mut findings = Vec::new();

        for dep in &usf.dependencies {
            // 无 hash 的依赖
            if dep.hash.is_none() {
                findings.push(Finding {
                    severity: Severity::Medium,
                    rule: "dependency-chain".into(),
                    message: format!("依赖 '{}' 无完整性 hash", dep.name),
                    location: format!("dependencies.{}", dep.name),
                    suggestion: "添加 sha256 hash 确保依赖完整性".into(),
                });
            }

            // 版本范围过宽
            if dep.version.starts_with(">=") && !dep.version.contains(',') {
                findings.push(Finding {
                    severity: Severity::Low,
                    rule: "dependency-chain".into(),
                    message: format!("依赖 '{}' 版本范围无上界: {}", dep.name, dep.version),
                    location: format!("dependencies.{}", dep.name),
                    suggestion: "添加版本上界，如 >=1.0.0, <2.0.0".into(),
                });
            }
        }

        // Chain 中引用的技能也算隐式依赖
        if let Logic::Chain(chain) = &usf.logic {
            for step in &chain.steps {
                let declared = usf.dependencies.iter().any(|d| d.name == step.skill);
                if !declared {
                    findings.push(Finding {
                        severity: Severity::Medium,
                        rule: "dependency-chain".into(),
                        message: format!(
                            "Chain 步骤引用技能 '{}' 但未在 dependencies 中声明",
                            step.skill
                        ),
                        location: "logic.chain vs dependencies".into(),
                        suggestion: "在 dependencies 中显式声明此技能".into(),
                    });
                }
            }
        }

        Ok(findings)
    }
}

// crates/evo-cli/src/commands/convert.rs

use clap::Args;

#[derive(Args)]
pub struct ConvertCmd {
    /// 源技能文件路径
    pub input: PathBuf,

    /// 目标生态（或 "all"）
    #[arg(long, short)]
    pub to: String,

    /// 输出目录
    #[arg(long, short, default_value = ".")]
    pub output: PathBuf,

    /// 最低保真度要求
    #[arg(long, default_value = "0.8")]
    pub min_fidelity: f64,

    /// 安全等级
    #[arg(long, default_value = "standard")]
    pub security: SecurityLevel,

    /// 跳过安全扫描
    #[arg(long)]
    pub skip_security: bool,

    /// 显示详细损失报告
    #[arg(long)]
    pub show_loss: bool,

    /// 源生态（不指定则自动检测）
    #[arg(long)]
    pub from: Option<String>,
}

pub fn execute(cmd: ConvertCmd) -> Result<()> {
    let raw = std::fs::read(&cmd.input)?;
    let engine = ConvertEngine::new();

    let options = ConvertOptions {
        security_level: cmd.security,
        skip_security: cmd.skip_security,
        min_fidelity: cmd.min_fidelity,
    };

    // 自动检测或使用指定的源生态
    let source = match &cmd.from {
        Some(s) => s.as_str(),
        None => engine.detect(&raw)?,
    };

    println!("📦 Input: {} ({})", cmd.input.display(), source);

    if cmd.to == "all" {
        let results = engine.convert_all(&raw, source, &options)?;
        for result in &results {
            print_result(result, cmd.show_loss);
            let filename = output_filename(&cmd.input, &result.target_ecosystem);
            let path = cmd.output.join(&filename);
            std::fs::write(&path, &result.data)?;
        }
        println!("\n⚡ Done — {} ecosystems", results.len());
    } else {
        let result = engine.convert(&raw, source, &cmd.to, &options)?;
        print_result(&result, cmd.show_loss);
        let filename = output_filename(&cmd.input, &cmd.to);
        let path = cmd.output.join(&filename);
        std::fs::write(&path, &result.data)?;
        println!("\n⚡ Done");
    }

    Ok(())
}

fn print_result(result: &ConvertResult, show_loss: bool) {
    // 安全评分
    if let Some(sec) = &result.security_report {
        let emoji = if sec.score >= 90 { "🟢" }
                    else if sec.score >= 70 { "🟡" }
                    else { "🔴" };
        println!("🔒 Security: {} {}/100", emoji, sec.score);
    }

    // 保真度
    let fidelity = result.loss_report.fidelity;
    println!("📊 Fidelity: {:.2}", fidelity);

    // 损失摘要
    let loss = &result.loss_report;
    println!("   ✅ Preserved: {} fields", loss.preserved.len());
    if !loss.degraded.is_empty() {
        println!("   🟡 Degraded:  {} fields", loss.degraded.len());
    }
    if !loss.lost.is_empty() {
        println!("   ❌ Lost:      {} fields", loss.lost.len());
    }

    // 详细损失
    if show_loss {
        println!();
        if !loss.degraded.is_empty() {
            println!("   🟡 Degraded details:");
            for item in &loss.degraded {
                println!("      {} → {}", item.field, item.reason);
            }
        }
        if !loss.lost.is_empty() {
            println!("   ❌ Lost details:");
            for item in &loss.lost {
                println!("      {} → {}", item.field, item.reason);
                println!("        💡 {}", item.suggestion);
            }
        }
    }

    println!("   ✅ {} → done", result.target_ecosystem);
}

## 十一、设计原则

```
1. 技能是原子单元
   不做胶囊/包级别的转换
   技能是最小可复用单元，粒度合适，转换精确

2. 有损透明
   转换不可能总是无损的
   但损失必须透明 — 用户看到保真度和损失报告后自己决定

3. 安全不可跳过（默认）
   安全扫描默认开启
   Critical 级别问题直接阻断转换
   用户可以 --skip-security 但这是显式的风险接受

4. 适配器可插拔
   新生态 = 新 crate，实现 SkillAdapter trait
   不需要改动引擎核心

5. 离线优先
   核心转换完全离线
   市场是可选的增值层
   WASM 让浏览器也能离线转换

6. 格式忠实
   USF 不发明新语义
   USF 是各生态技能格式的最大公约数 + 联合体
   尽可能保留原始信息，即使目标生态用不上
```
